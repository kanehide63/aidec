【GitHubへのアップロード】

1. GitHubのAIDECホームページ用リポジトリを開きます。
2. Add file → Upload files を選択します。
3. このフォルダー内の10ファイルをアップロードします。
4. 同名ファイルは新しい内容へ上書きされます。
5. Commit changes を押します。
6. GitHub Pagesへの反映後、navigator.htmlを再読み込みして動作をご確認ください。

※フォルダー自体ではなく、フォルダー内のファイルをリポジトリ直下へアップロードしてください。
※正式なAIDEC Navigatorブランド資産を使用しており、画像の描き直しは行っていません。
