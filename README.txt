AIDECホームページ ブランドイントロ完成版

【動作】
1. ホームページを開くと白背景のブランドイントロを表示
2. AIDECシンボルのAが静かに現れる
3. 青い玉が画面下から弧を描いて上昇し、定位置へ到達
4. 控えめな光とともにブランドシンボルが完成
5. AIDECと正式名称を時間差で表示
6. 約7.2秒後、現在のホームページトップが約1秒かけてフェードイン
7. フェードイン後にトップページのキャッチコピーが1文字ずつ展開

【スキップ】
画面右上の「SKIP」を押すと、約0.7秒のフェードを経てホームページトップへ移ります。
Escキーでもスキップできます。
通常終了・スキップのどちらでも、ホームページ表示後にキャッチコピーの文字展開が始まります。

【アクセシビリティ】
端末で「視差効果を減らす／アニメーションを減らす」が設定されている場合は、短縮した静かな表示に自動変更します。

【主な変更ファイル】
・index.html：ブランドイントロの画面構造と専用JavaScriptの読み込みを追加
・style.css：ブランドイントロ、青い玉、光、フェード、スマートフォン対応を追加
・brand-intro.js：自動終了、スキップ、フェード移行を実装

【ヘッダーナビゲーション】
AIDECについて → サービス → コンパス → 私たちの考え方 → 代表メッセージ
「コンパス」はOUR COMPASSセクションへ移動します。
