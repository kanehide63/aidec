AIDEC Navigator 静止ロゴ正式仕様

【変更内容】
・AIDEC Navigatorログインページのブランドイントロ・待機時間・発光演出を削除
・正式な「AIDEC Navigator文字ありロゴ」を静止画像として表示
・ホームページのANロゴを選択すると、待ち時間なくログイン画面を表示
・ログイン案内文、ID・Password入力欄、ログインボタン、準備中表示は変更なし
・既存のAIDEC公式ホームページおよびホームページ上のAN入口は変更なし

【変更ファイル】
・navigator.html
・navigator.css
・navigator.js

【同梱ファイル】
GitHub Pagesでの取り違えを防ぐため、関連する既存ファイルと正式ブランド資産も同梱しています。
アニメーション用画像は使用しないため、同梱していません。

【アップロード方法】
1. ZIPを展開します。
2. GitHubのAIDECホームページ用リポジトリを開きます。
3. Add file → Upload files を選択します。
4. このフォルダー内のWeb用ファイル8点をリポジトリ直下へアップロードします。
5. 同名ファイルは上書きし、Commit changesを実行します。
6. 公開反映後、ホームページのANロゴを選択し、ログイン画面が直ちに表示されることを確認します。

※この説明ファイルはGitHubへアップロードする必要はありません。
